# SEO Route Inventory

## Repository audit snapshot

- Framework: React 18 + Vite 6 SPA
- Routing: `react-router` (`BrowserRouter`) in `/home/runner/work/sagestone.com-v2/sagestone.com-v2/src/app/App.tsx`
- Rendering: client-rendered application (no server-side metadata rendering)
- Metadata system: centralized route SEO config + runtime head manager (`src/app/seo/*`)
- Canonical helper: `buildCanonicalUrl` in `src/app/seo/site-url.ts`
- Sitemap source: generated from `src/app/seo/route-seo.ts` via `scripts/generate-sitemap.mjs`
- Robots source: static `public/robots.txt`
- Structured data: centralized builders in `src/app/seo/structured-data.ts`, injected by `SeoHead`
- Internal navigation: header + footer + service index cards + contextual buttons/links
- Blog architecture: `/blog` index + per-article routes under `/blog/*`
- Image strategy: lazy loading by default, explicit eager LCP images, explicit image dimensions on key images
- Font loading: Google Fonts preconnect + stylesheet links in `index.html`
- Third-party scripts: no analytics/chat widgets found in repository code
- Redirect handling: legacy service routes redirected in router and `public/_redirects`
